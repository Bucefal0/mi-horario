# Organizador de Aula y Bitácora Docente | Matemáticas

Panel interactivo de asistencia, horario semanal y bitácora pedagógica para secundaria.

- Horario semanal completo con recesos escalonados por grado.
- Tarjeta en vivo con cuenta regresiva y módulo actual.
- Bitácora local persistida en el navegador (LocalStorage).
- Modo proyector y tema oscuro/claro.
- Exportación e importación de respaldos en JSON.
